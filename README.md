# 生活メンテナンス

運動・片付け・自炊などを「毎日」「週○回」の目標で管理する個人用Webアプリです。連続日数ではなく、今週の達成を重視します。

## 機能

- 曜日ボタンを1クリックで完了／未完了に切り替え
- 毎日の達成数、週の目標回数、CLEAR表示、全体の目標進捗
- 今日の曜日を枠線と小さな点で表示
- タスクの追加・編集・確認付き削除、メモ、表示順
- 月曜始まりの週表示、前週・次週への移動、今週に戻る
- PC・スマートフォンに対応したダークモード
- 初回のみ4つのサンプル習慣を作成

## 起動方法

4ファイルを同じフォルダーに置き、`index.html` をブラウザーで開いてください。サーバー、ビルド、外部フレームワーク、ネット接続は不要です。日常利用にはブックマークすると便利です。最新版のChrome・Edge・Firefox・Safariなど、dialog / structuredCloneに対応したブラウザーを使用してください。

## データ保存

localStorageの `life-maintenance` キーに、`schemaVersion: 1`、`tasks`、`records`、`settings` をJSON形式で保存します。チェック履歴はタスクIDと `YYYY-MM-DD` のローカル日付で管理します。UTC文字列への変換は行いません。週の開始日は設定として月曜日を保存します。

リロードしてもタスク、メモ、表示順、チェック履歴は残ります。起動時は常に今週を表示します。目標や名前の編集は過去の週の表示にも反映されますが、チェック自体は保持されます。削除は内部的に非表示とし、チェック記録がある週には「削除済み」の読み取り専用カードを表示します。週を移動してもデータは削除しません。

**localStorageを消すとデータも消えます。** ブラウザーやプロファイルごとに保存先は異なり、端末間の同期はありません。プライベートブラウジングでは終了時に失われる場合があります。ファイルを移動した場合の保存先やfile URLでのlocalStorageの動作はブラウザーに依存するため、同じブラウザーで同じ場所から開いてください。

保存に失敗した場合は画面に通知し、変更を確定しません。読み込み不能・未対応のschemaVersionの場合は既存データを上書きしません。

## 確認結果

Edgeの独立したテスト用ブラウザーで、初回起動、チェックON/OFF、毎日7/7と週目標以上のCLEAR、前週・次週、月をまたぐ週（2026/9/28〜10/4）、年をまたぐ週（2026/12/28〜2027/1/3）、追加・編集・削除と削除キャンセル、削除後の履歴、リロード後の保持を確認しました。日本と米国のタイムゾーンで日付キーも確認しました。

PC幅1200pxとスマートフォン幅375pxで画面を確認し、横方向のはみ出しやJavaScriptエラーはありませんでした。未対応のschemaVersionのデータを上書きせず、編集を無効化する動作も確認済みです。
